# 东方幻想乡 · 纸上相逢 — GitHub 浏览版

网址：https://XWJDream.github.io/gensokyo-sketchbook-pages/

东方 Project 非官方同人图鉴：48 位角色、六册地图 / 29 处地点、六章世界手帖与四幅独立场景。
人物搜索、筛选、本机收藏、大图、地图拖动与缩放、场景翻页均可独立使用。
插图含 AI 生成内容，原作：ZUN / 上海爱丽丝幻乐团。

本仓库仅保存公开网页与插图，用于 GitHub Pages 静态部署。主源码仓库保持私有。
画廊的作品浏览、登录、上传与审核需要服务端，入口会说明并链接到完整版，不会在此收集或假装提交作品。
本机收藏与完整版中的收藏不会跨域同步。

完整版：https://gensokyo-sketchbook.silverjoy8.chatgpt.site/

## 更新与发布

`main` 分支根目录由 GitHub Pages 发布；`.nojekyll` 保留普通静态文件布局。
更新时从主项目导出网页脚本、样式和 assets，并保留本仓库专用的 gallery.js 入口说明。
不要复制任何环境变量、密钥、账号数据、数据库或用户上传内容。

GitHub Pages 在不同网络的访问情况可能不同，本镜像不保证所有地区的网络连通性。
